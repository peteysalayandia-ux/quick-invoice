# Quick Invoice

A fast, installable invoice app that works in the browser and offline.

## Features

- Add and remove line items with automatic subtotal, tax, and total calculations
- Save invoice data automatically in the browser
- Print an invoice or save it as a PDF
- Install as a Progressive Web App
- Responsive layout for desktop and mobile
- No build step or server-side dependencies

## Run locally

Serve the folder with any static web server, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
